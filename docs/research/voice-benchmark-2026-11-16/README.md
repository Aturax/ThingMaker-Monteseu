# Comparación de dictado en Windows

El 16 de noviembre de 2026 se compararon Parakeet y Whisper en CPU con Whisper y Gemma en GPU usando los mismos cuatro clips sintéticos en español e inglés. Se hicieron tres pasadas por clip. Las pruebas midieron la latencia de procesamiento de archivos y motivaron una segunda comparación con [voz humana](../voice-benchmark-human-windows-2026-11-16.md). Las muestras sintéticas no permiten evaluar la precisión ante acentos, ruido o habla espontánea.
